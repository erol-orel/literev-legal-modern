# lr-contracts

Standalone contracts package with typed models shared by the query, search, and
clustering libraries.

## Layout

- `src/lr_contracts/`: package source code
- `tests/`: package-local test suite
- `pyproject.toml`: standalone package metadata

## Development

Install this package in editable mode from the library root when working on it
independently:

```bash
pip install -e .
pytest
```
